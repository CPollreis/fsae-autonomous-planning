# autonomous-system-planning

Personal planning repo for UMSAE's Driverless (DV) program — research, timelines, and reference docs, kept separate from the team org so this can stay a rough working space.

The `main` branch is kept minimal on purpose. The full working dump — timeline research, rules digests, subsystem deep dives, monorepo research, and diagrams — lives on the `init-brain-dump` branch until it's cleaned up and worth merging.
